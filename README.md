## SignTalk: AI-Based Sign Language to Text & Speech Translator

### 📝 Project Description

**SignTalk** is an AI/ML-based project designed to bridge the communication gap between the deaf and mute community and the general public. The system uses Computer Vision and Deep Learning to capture hand gestures in real-time, extract spatial landmarks, and translate dynamic gesture sequences into readable text and audible speech.

The project focuses on studying sign language recognition techniques, utilizing tools like Google MediaPipe for feature extraction, and deploying sequential models like LSTM to understand moving signs. It acts as a low-cost, AI-powered virtual interpreter using a standard webcam.

This repository contains the Seminar Presentation and Project Initiation (SPI – 315003) work, including the seminar presentation, SPI report, and research papers related to Sign Language Recognition.
